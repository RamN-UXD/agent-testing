How to import into Figma:
1. Install the "Figma JSON Importer" community plugin → load document.json to recreate all artboards & layers as native Figma frames.
2. Use the "Design Tokens" plugin → import styles/colors.json and styles/typography.json as Figma styles.
3. Assets in assets/images/ are pre-extracted — drag them directly into your Figma canvas.
